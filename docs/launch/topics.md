# Suggested GitHub topics

For `zeusstudiodev/worklings` (the gear icon next to "About" on the repository page). GitHub allows up to 20. These twelve are
the ones people search for, and each is true of the code today. Topics are lowercase with hyphens.

| Topic | Why it is true |
|---|---|
| `claude-code` | Worklings runs and watches the user's own Claude Code; it is the descriptor, as in "for Claude Code" |
| `claude-code-plugin` | The repository is also a Claude Code plugin and marketplace (`plugin/`, installed as `worklings@worklings`) |
| `ai-agents` | A company of agent sessions with roles, tasks and messages |
| `multi-agent` | Many sessions work in parallel and hand work to each other |
| `agent-orchestration` | A CEO drafts the org, heads split the work, and an inbox gathers questions and approvals |
| `subagents` | The studio generator writes a project's Claude Code subagents, rules and workflows |
| `mcp` | The org tools are an MCP server on `127.0.0.1` that each person's session connects to |
| `ai-coding` | It is for people who write software with an AI coding agent |
| `react-three-fiber` | The office is drawn with React Three Fiber |
| `threejs` | Three.js underneath, with low-poly CC0 art |
| `typescript` | The command line, server and web app are TypeScript (Node runs `src/` directly) |
| `developer-tools` | A command-line tool and local web app for people who write software |

Left out on purpose: `chatgpt`, `openai` and `autogpt` (it does not work with them), `claude` alone (a bare brand topic
suggests more than "for Claude Code"), and `llm` (too broad to help anyone find it).
